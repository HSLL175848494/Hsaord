# Hsaord

面向 Android 用户的事件合约自动交易工具，支持 Binance（币安）BTCUSDT 事件合约。软件与桌面端共用同一套交易信号，集成信号接收、自动下单、风险控制与交易统计等功能。

## 核心功能

软件接收包含交易方向、置信度和有效期的实时信号，并根据用户设置的下单金额与信号范围自动执行交易。风控功能支持限制订单数量、累计投入金额、最大亏损和止盈金额，帮助用户控制交易风险。

软件还会跟踪待结算订单，保存订单明细与结算结果，并展示收益表现、胜负比例和月度交易热力图，方便用户了解整体交易情况。
